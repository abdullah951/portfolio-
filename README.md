# 🔬 Featured R&D Projects

### PAIV (Persons Age and Gender Identification in Videos)
*Endorsed by Evestors Limited, UK*  
An age-restricted access control system for online streaming websites utilizing live demographic classification. I designed algorithms to flag live streaming for underage content in real-time. The system also features a parent-notification architecture integrated with a mobile application to trigger instant alerts if registered children appear in unauthorized streams.

### Enterprise Hospital ERP (iHealthCure)
[iHealthCure] is an EMR (Electronic Medical Record) system and comprehensive digital healthcare solution designed to modernize hospital operations across the UAE and Pakistan.  
**ML & Architecture Focus:** I researched and developed an end-to-end MLOps pipeline deploying containerized ensemble models (XGBoost) for anomaly detection in diagnostic results. I also conducted applied NLP research to extract structured entities from unstructured clinical notes, significantly minimizing manual errors and allowing hospital staff to focus on patient care.
